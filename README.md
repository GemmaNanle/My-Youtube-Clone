# 🎬 YouTube Clone

A modern YouTube-inspired video streaming platform built with React. This project recreates the core look and feel of a video-sharing platform with a clean, responsive, and user-friendly interface.

## ✨ Features

- 🏠 Home page with video cards
- 🔍 Search interface
- 🎥 Video watch page
- 📂 Category navigation
- 📱 Responsive design
- 🌙 Dark-themed interface
- 📺 Video thumbnails and metadata
- 👤 Channel information
- 🔔 Subscription interface
- 📚 Library, History, Liked Videos and Watch Later sections
- ⚡ React-based component architecture

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Vite

## 🎯 Project Purpose

This project was created to practice building a real-world web application using React, reusable components, routing, state management, and responsive UI design.
